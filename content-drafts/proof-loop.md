# TMT — The Proof Loop

Internal. Not a public page.

**The rule: no baseline, no ROI claim.** If it was not measured before the work started, it cannot
be claimed afterwards. This is the difference between a business with case studies and a business
with anecdotes.

---

## 1. Capture the baseline on day one

Create this record for **every** engagement, during the audit, before anything changes. If the
client cannot produce a number, write down how it was estimated and mark it as an estimate.

| Measure | Before | 30 days | 90 days |
|---|---|---|---|
| Hours of manual work per week | | | |
| Lead-response time | | | |
| Quotes awaiting follow-up | | | |
| Missed calls / missed leads | | | |
| Rework, callbacks, admin errors | | | |

Notes to record alongside it:
- How each number was obtained (phone system report, CRM export, owner estimate)
- Who owns each process today
- What changed between measurements, so improvement can be attributed honestly

## 2. Measure again at 30 and 90 days

Put both dates in the calendar at the time the audit is delivered. A check-in that depends on
remembering does not happen — which is the same lesson the audit sells.

## 3. Only after a measurable result, ask for three things

In this order, in one conversation:

1. **A truthful Google review.** Ask for their honest experience. Nothing else.
2. **Permission for a short case study.** Written permission. Anonymise by trade and market size
   unless they explicitly agree to be named.
3. **One introduction** to another owner who has the same problem.

## What is never done

- **No incentives for reviews.** No discounts, no gifts, no credit, nothing conditioned on leaving
  a review or on the review being positive. The FTC's rule on fake and manipulated reviews makes
  compensation tied to sentiment a legal problem, not just a reputational one.
- **No writing the review for them**, and no editing what they wrote.
- **No case study without written permission**, and none that names a client who did not agree.
- **No before/after number that was not measured**, including on the website, in decks, in videos,
  and in the vendor outreach.

## Why this is the operating system, not admin

TMT has zero testimonials and zero case studies today. That is the single biggest constraint on
sales — bigger than traffic, bigger than the website. Two measured case studies are worth more than
another twenty pages, and this loop is the only thing that produces them.
